### 📦 Repository Overview

This public repository serves as the official distribution portal, documentation hub, and community extension registry for **Yomu Desktop Reader**:

* **[Official Web Portal](https://olivo28.github.io/yomu-public/)**: High-fidelity product tour, native reader simulation, and architectural documentation.
* **[Extension Marketplace (`/market/registry.json`)](./market/registry.json)**: Canonical index of verified `.yomu` scraper extensions for one-click installation inside Yomu.
* **[Community Issue Tracker](https://github.com/olivo28/yomu-public/issues)**: Report broken scrapers, suggest new sites, or file reader bug reports.
